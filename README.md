# Booked Profit Tracker

A mobile-friendly PWA for tracking **sold stock trades only**.

It calculates:
- Total booked profit
- Total cost and sale value
- Return % per trade
- CAGR for each completed trade
- Overall realized XIRR using actual buy/sell cash flows

Data is stored locally in the browser. No broker credentials are used.

## GitHub Pages
Publish the repository from `main` / root using GitHub Pages. GitHub Pages supports static HTML/CSS/JavaScript sites and uses `index.html` as an entry file.
