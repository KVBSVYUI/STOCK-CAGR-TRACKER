🛡️ Administrator Setup

This version uses Firebase Spark only. No Cloud Functions or billing are required for the admin dashboard.

One manual Firebase step is required:

  1. Copy the User ID shown below.
  2. Open Firebase Console → Firestore Database → Data.
  3. Create a collection named admins.
  4. Create a document whose ID is exactly your User ID.
  5. Add a boolean field named admin with value true.
Checking sign-in…

After saving that document, return to the tracker, refresh once, and the 🛡️ Admin option will appear inside ☰ Menu.

Security rules prevent the web app from creating or changing admin records, so another normal user cannot promote themselves.
